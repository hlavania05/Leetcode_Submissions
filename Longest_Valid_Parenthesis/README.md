# Longest Valid Parentheses

## Solutions

### 1. Brute Force Approach
- Check every possible substring.
- Validate each substring using a counter.
- Time Complexity: O(n³)
- Space Complexity: O(1)

### 2. Stack-Based Optimized Approach
- Uses a stack to track indices.
- Efficiently computes the maximum valid substring length.
- Time Complexity: O(n)
- Space Complexity: O(n)
